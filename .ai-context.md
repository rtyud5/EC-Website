# E-Commerce Marketplace — AI Context

> Đây là file context trung tâm. Các file riêng của từng AI tool (`AGENTS.md`, `CLAUDE.md`, `.cursorrules`, v.v.) đều tham chiếu nội dung này.

## Project
C2C multi-vendor e-commerce marketplace (Shopee-style) with Vietnamese UI. TypeScript monorepo.

## Tech Stack
| Layer | Tech |
|-------|------|
| **API** | Express + Prisma ORM + PostgreSQL + Redis + Zod + JWT |
| **Web** | Next.js 14 (App Router) + TailwindCSS + Zustand + React Query |
| **Infra** | Docker Compose (dev + prod) + Nginx reverse proxy |
| **Payment** | PayOS (Vietnamese gateway) |

## Architecture Patterns

### Backend — Module Pattern
```
src/modules/[name]/
  ├── [name].routes.ts         # Router + middleware chain
  ├── [name].controller.ts     # asyncHandler(fn) → delegates to service
  ├── [name].service.ts        # Business logic + Prisma queries
  └── [name].validation.ts     # Zod: z.object({ body, query, params })
```

### Frontend — State Management
```
Server state → React Query hooks (hooks/useProducts.ts, useOrders.ts...)
Client state → Zustand stores (store/auth.store.ts, cart.store.ts, wishlist.store.ts)
```

### Auth Flow
```
Login → api.post("/auth/login") → setAuth(user, token)
  → Zustand persist (localStorage "auth-storage")
  → Cookies synced (auth-token, user-role) for Next.js middleware
  → API interceptor reads token from localStorage for Authorization header
```

## Code Conventions
- **UI text**: Vietnamese (labels, messages, errors, placeholders)
- **Code**: English identifiers, Vietnamese/English comments
- **Styling**: TailwindCSS only. Orange (#f97316) for shop, Indigo (#6366f1) for landing
- **Font**: Inter (Google Fonts)
- **Components**: `"use client"` on all interactive components
- **Naming**: PascalCase components, camelCase hooks/stores, kebab-case routes

### File Naming
| Type | Pattern | Example |
|------|---------|---------|
| Component | PascalCase.tsx | `ProductCard.tsx` |
| Hook | use[Name].ts | `useProducts.ts` |
| Store | [name].store.ts | `auth.store.ts` |
| Type | [name].type.ts | `product.type.ts` |
| Validation | [name].validation.ts | `auth.validation.ts` |

## Key Code Patterns

### React Query Hook
```typescript
export function useXxx(params?) {
  return useQuery<Type[]>({
    queryKey: ["xxx", params],
    queryFn: async () => {
      const res = await api.get("/xxx", { params });
      return res.data.data || [];
    },
  });
}
```

### Zustand Store
```typescript
export const useXxxStore = create<XxxStore>()(
  persist((set, get) => ({
    items: [],
    addItem: (item) => set((s) => ({ items: [...s.items, item] })),
  }), { name: "xxx-storage" })
);
```

### API Controller
```typescript
export const xxxController = {
  getAll: asyncHandler(async (req: Request, res: Response) => {
    const result = await xxxService.getAll(req.query);
    ok(res, result);
  }),
};
```

### Error Handling
```typescript
// Throw
throw ApiError.badRequest("Message");
throw ApiError.unauthorized("Message");
throw ApiError.notFound("Message");

// Chain: controller → asyncHandler → catch → errorMiddleware → JSON response
```

## Database (Prisma — 12 Models)
User, Seller, Category, Product, CartItem, Order, OrderItem, Payment, Discount, Commission, AIModel
- User roles: USER | ADMIN | SELLER
- Order status: PENDING → CONFIRMED → PROCESSING → SHIPPED → DELIVERED → COMPLETED
- Seller requires admin approval (PENDING → APPROVED)

## Important Notes
- Run `npx prisma generate` after schema changes
- CORS_ORIGIN supports comma-separated origins
- JWT token cast `as any` for expiresIn (jsonwebtoken type issue)
- Test accounts after seed: admin@ecommerce.vn/admin123, user@ecommerce.vn/user123

## Setup
```bash
# API
cd ecommerce-api && npm i && npx prisma generate && npx prisma migrate dev && npx prisma db seed && npm run dev

# Web
cd ecommerce-web && npm i && npm run dev

# Docker
docker-compose -f docker-compose.dev.yml up
```
